## 合成规模记录

[scale.json](validation/scale.json) 是 2026-10-15 本机工作负载：200 源、100,000 篇元数据、20,000 份正文，约 500 MiB HTML。数据库约 1.23 GB，索引约 111 MB；30 次样本的列表 p95 0.657 ms、中文搜索 p95 31.8 ms；一致备份 10.09 秒、恢复 14.57 秒，恢复数量、完整性及外键一致。

这是当时源码的合成场景，不是加入后续完整未读统计后的性能复测，也不能外推 NAS、混合峰值内存、30 分钟空闲 CPU 或功耗。独立搜索实验也不替代产品集成验证。

## 保留的限制

- 尚无目标硬件完整延迟/内存/CPU/功耗测量；容器 512 MiB 上限是工程设置。
- Linux AMD64 在本机模拟运行；未做真实 iOS Safari/Android 浏览器专项验收。
- 真实站点全文质量、检索召回率、摘要事实支持/遗漏/引用完整性及大规模模型费用仍需金标准和人工评估。
- Miniflux 专有认证、代理、改写/过滤配置只报告差异，默认阻止有不兼容设置的导入；不声称全部兼容。
- 尚无向量检索、重排、任意工具执行、多 Agent、系统外消息推送、离线同步、媒体下载或原生 App。
