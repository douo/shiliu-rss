# SQLite / 中文搜索选型实验

这是独立、可删除的选型证据，不是产品代码。2026-10-15 已在 macOS ARM64 上通过。仅用合成文本，临时数据库由测试框架创建和删除，不访问 NAS、不监听端口。

## 重现

从此目录执行：

```sh
go test -v ./...
```

go.mod 指定 Go 1.27.2，固定 `modernc.org/sqlite v1.60.1`，go.sum 保存校验信息。正常 Go 自动工具链配置可下载所需版本，无需升级全局 Homebrew Go。

## 已验证

- 实际运行 SQLite 3.53.4，WAL、foreign_keys 与 synchronous=FULL 生效。
- 默认 unicode61 和 trigram 无法直接匹配连续中文里的两字查询“音乐”。
- 汉字拆分后的字面短语支持两字、单字、中英混排、英文大小写/重音归一；反序与不相邻字符不误匹配。
- 用户输入的双引号被转义，不允许输入改变 FTS 查询语法。
- contentless-delete 表不额外提供一份可读正文；事务清理源正文及索引后，标题、笔记、摘要仍可查。
- 回滚清理事务时正文的索引命中仍在。

已完成一次 `CGO_ENABLED=0 GOOS=linux GOARCH=amd64 GOAMD64=v1 go test -c`；`file` 确认产物为静态链接 x86-64 ELF。编译产物位于本机临时目录，检查后已移除。没有在 NAS 执行它。

## 边界

这不是基准测试，不衡量 NAS CPU/内存/功耗、索引增长或抓取性能。实验只验证单个字面短语；产品的多项 AND、HTML 转文本、链接列、到期权限过滤、排序/分页、并发事务与重建仍需实现及测试。索引不保存完整列值不代表没有词项存储，也不代表删除时立即物理擦除磁盘残留。

生产方案与资源预算见 [技术选型](../../docs/technology.md)。
